Human ライブラリ

AIを活用した3D顔検出＆回転トラッキング、顔の特徴記述＆認識、身体ポーズトラッキング、3D手＆指トラッキング、虹彩分析、年齢・性別・感情予測、視線トラッキング、ジェスチャー認識、身体セグメンテーション

ハイライト

  • ほとんどのサーバーサイドおよびクライアントサイドの環境・フレームワークと互換性あり
  • ユースケースに応じてオンデマンドで切り替え可能な複数の機械学習モデルを統合
  • 関連するモデルはアテンションパイプライン内で実行され、必要な時に詳細情報を提供
  • あらゆるタイプの入力画像の品質を向上できる、最適化された入力前処理
  • フレームの変化を検出し、必要なモデルのみをトリガーしてパフォーマンスを向上
  • 処理パフォーマンスに関わらずスムーズな結果を提供する、インテリジェントな時間補間（Temporal Interpolation）
  • シンプルで統一されたAPI
  • 画像、動画、Webカメラの組み込み処理に対応

互換性

ブラウザ:

  • デスクトップおよびモバイルプラットフォームの両方に対応
  • WebGPU、WebGL、WASM、CPU バックエンドに対応
  • WebWorker 上での実行に対応
  • WebView に対応
  • プライマリプラットフォーム: Chromium系ブラウザ
  • セカンダリプラットフォーム: Firefox、Safari

NodeJS:

  • TensorFlowのバイナリが利用できないアーキテクチャでの実行用に WASM バックエンドに対応
  • TensorFlow共有ライブラリを介したソフトウェア実行による tfjs-node に対応
  • TensorFlow共有ライブラリおよびnVidia CUDAを介したGPUアクセラレーション実行による tfjs-node に対応
  • サポート対象バージョン: 14.x 〜 22.x
  • ※NodeJS バージョン 23.x は、破壊的変更および @tensorflow/tfjs との問題のためサポート対象外です。

コード例

Humanを使用して動画入力を処理し、内部の描画ヘルパー関数を使用して画面に結果を描画するシンプルなアプリです。

Promiseを使用する場合:

// デフォルト値を使用したシンプルな設定でHumanのインスタンスを作成
const config = { backend: 'webgl' };
const human = new Human.Human(config);
// ページから入力用 HTMLVideoElement と出力用 HTMLCanvasElement を取得
const inputVideo = document.getElementById('video-id');
const outputCanvas = document.getElementById('canvas-id');

function detectVideo() {
  // デフォルト設定で処理を実行
  human.detect(inputVideo).then((result) => {
    // resultオブジェクトには検出された詳細情報と
    // 処理されたキャンバス自体が含まれています
    // 最初に処理されたフレームをキャンバスに描画します
    human.draw.canvas(result.canvas, outputCanvas);
    // 次に同じキャンバス上に検出結果を描画します
    human.draw.face(outputCanvas, result.face);
    human.draw.body(outputCanvas, result.body);
    human.draw.hand(outputCanvas, result.hand);
    human.draw.gesture(outputCanvas, result.gesture);
    // 即座に次のフレームへとループします
    requestAnimationFrame(detectVideo);
    return result;
  });
}

detectVideo();

async/awaitを使用する場合:

// デフォルト値を使用したシンプルな設定でHumanのインスタンスを作成
const config = { backend: 'webgl' };
const human = new Human(config); // Humanのインスタンスを作成
const inputVideo = document.getElementById('video-id');
const outputCanvas = document.getElementById('canvas-id');

async function detectVideo() {
  const result = await human.detect(inputVideo); // 検出を実行
  human.draw.all(outputCanvas, result); // すべての結果を描画
  requestAnimationFrame(detectVideo); // ループを実行
}

detectVideo(); // ループを開始

イベントを使用する場合:

// デフォルト値を使用したシンプルな設定でHumanのインスタンスを作成
const config = { backend: 'webgl' };
const human = new Human(config); // Humanのインスタンスを作成
const inputVideo = document.getElementById('video-id');
const outputCanvas = document.getElementById('canvas-id');

human.events.addEventListener('detect', () => { // 検出が完了した時にイベントがトリガーされる
  human.draw.all(outputCanvas, human.result); // すべての結果を描画
});

function detectVideo() {
  human.detect(inputVideo) // 検出を実行
    .then(() => requestAnimationFrame(detectVideo)); // 検出完了後に次のフレームの処理を開始
}

detectVideo(); // ループを開始

検出ループと描画ループを分離し、補間された結果を使用してスムーズな動画処理を行う場合:

const human = new Human(); // Humanのインスタンスを作成
const inputVideo = document.getElementById('video-id');
const outputCanvas = document.getElementById('canvas-id');
let result;

async function detectVideo() {
  result = await human.detect(inputVideo); // 検出を実行
  requestAnimationFrame(detectVideo); // 検出ループを実行
}

async function drawVideo() {
  if (result) { // 結果が利用可能かチェック
    const interpolated = human.next(result); // 直近の既知結果を使用して平滑化された結果を取得
    human.draw.all(outputCanvas, interpolated); // フレームを描画
  }
  requestAnimationFrame(drawVideo); // 描画ループを実行
}

detectVideo(); // 検出ループを開始
drawVideo(); // 描画ループを開始

手動のフレームごとループの代わりに、組み込みの完全動画処理を使用する場合:

const human = new Human(); // Humanのインスタンスを作成
const inputVideo = document.getElementById('video-id');
const outputCanvas = document.getElementById('canvas-id');

async function drawResults() {
  const interpolated = human.next(); // 直近の既知結果を使用して平滑化された結果を取得
  human.draw.all(outputCanvas, interpolated); // フレームを描画
  requestAnimationFrame(drawResults); // 描画ループを実行
}

human.video(inputVideo); // 結果を継続的に更新する検出ループを開始
drawResults(); // 描画ループを開始

動画処理を完全に管理してくれる組み込みWebカメラヘルパーメソッドを使用する場合:

const human = new Human(); // Humanのインスタンスを作成
const outputCanvas = document.getElementById('canvas-id');

async function drawResults() {
  const interpolated = human.next(); // 直近の既知結果を使用して平滑化された結果を取得
  human.draw.canvas(outputCanvas, human.webcam.element); // 現在のWebカメラフレームを描画
  human.draw.all(outputCanvas, interpolated); // フレームの検出結果を描画
  requestAnimationFrame(drawResults); // 描画ループを実行
}

await human.webcam.start({ crop: true });
human.video(human.webcam.element); // 結果を継続的に更新する検出ループを開始
drawResults(); // 描画ループを開始

さらにパフォーマンスを向上させるため、別々の Web Worker スレッドで検出を実行することも可能です。

入力形式

Human ライブラリは知られているすべての入力形式を処理できます： Image, ImageData, ImageBitmap, Canvas, OffscreenCanvas, Tensor, HTMLImageElement, HTMLCanvasElement, HTMLVideoElement, HTMLMediaElement

さらに、HTMLVideoElement および HTMLMediaElement は、以下にリンクする標準の <video> タグにすることが可能です：

  • ユーザーシステムの WebCam（Webカメラ）
  • サポートされている任意の動画タイプ（例: .mp4, .avi など）
  • HTML5 Media Source Extensions 経由でサポートされる追加の動画タイプ（例: hls.js を使用した HLS、dash.js を使用した DASH）
  • 組み込みサポートを使用した WebRTC メディアトラック

型定義 (TypeDefs)

HumanはTypeScriptの強力な型付けで記述されており、ライブラリで定義されているすべてのクラスの完全な型定義が types/human.d.ts にバンドルされ、デフォルトで有効になっています。

注: これには埋め込まれた tfjs は含まれません。 Human内部の埋め込み tfjs（human.tf ネームスペース）を使用しつつ完全な型定義も保持したい場合は、以下のコードを追加してください： 

import type * as tfjs from '@vladmandic/human/dist/tfjs.esm';
const tf = human.tf as typeof tfjs;

サイズの考慮からHumanには完全な TFJS 型定義が同梱されていないため、これはデフォルトでは有効になっていません。上記のように tfjs 型定義を有効にすると、@vladmandic/human/dist/tfjs.esm.d.ts で定義されている以下のプロジェクト依存関係（型定義のみが必要なため dev-only 依存）が追加されます：

  • @tensorflow/tfjs-core
  • @tensorflow/tfjs-converter
  • @tensorflow/tfjs-backend-wasm
  • @tensorflow/tfjs-backend-webgl

デフォルトモデル

Human ライブラリのデフォルトモデル：

  • 顔検出 (Face Detection): MediaPipe BlazeFace（Backバリエーション）
  • フェイスメッシュ (Face Mesh): MediaPipe FaceMesh
  • 顔の虹彩分析 (Face Iris Analysis): MediaPipe Iris
  • 顔の記述 (Face Description): HSE FaceRes
  • 感情検出 (Emotion Detection): Oarriaga Emotion
  • 身体分析 (Body Analysis): MoveNet（Lightningバリエーション）
  • 手の分析 (Hand Analysis): HandTrack & MediaPipe HandLandmarks
  • 身体セグメンテーション (Body Segmentation): Google Selfie
  • 物体検出 (Object Detection): CenterNet with MobileNet v3

オルタナティブモデル（代替モデル）も用意されており、設定変更によって有効化できます。 例えば、身体ポーズ検出はデフォルトで MoveNet Lightning を使用しますが、ユースケースに応じて、より高精度なMoveNet、複数人検出用の Multinet MultiPose、または PoseNet、BlazePose、EfficientPose に切り替えることが可能です。

詳細については、「設定の詳細」および「モデル一覧」を参照してください。

注

Humanとは、画像やWebカメラ映像から「顔・身体・手・視線・ジェスチャー・感情」などをAIでまとめて検出・分析できるJavaScript / TypeScript用のライブラリのこと
人間の状態や動きをWebブラウザやNode.js上で簡単に読み取るためのAIツールボックス

このアプリでは顔の検出・メッシュ・特徴量と、顔の向きの判定だけを使用していますが、それ以外も分析できるようです

分析対象 詳細・機能
顔（Face） 3D顔検出、468ポイントの顔メッシュ抽出、顔の特徴量の抽出と照合、年齢・性別・感情の予測
目・視線（Iris/Gaze） 虹彩の分析、どこを見ているかの視線トラッキング
身体（Body） ポーズ（骨格）トラッキング、人物と背景の切り分け（セグメンテーション）
手・指（Hand） 3Dでの手のひら・指関節のトラッキング、ジェスチャー認識

Humanは顔認証以外にも機能があるようです

Webカメラを使った顔認証（Face ID） ブラウザ上で本人確認を行い、ログインや本人認証に活用する。
バーチャルYouTuber（VTuber） / 3Dモデル操作 Three.jsやBabylon.jsと組み合わせて、Webカメラの映像からVRMモデル（3Dキャラ）の顔やポーズをリアルタイム動かす。
AR（拡張現実）フィルター・試着アプリ 顔のメッシュ情報を利用してメガネやメイクの試着、顔エフェクトを適用する。
ジェスチャー操作 手の動きやサインを認識して、画面の操作やゲームの操作を行う。

humanConfigの設定

filter：画像の前処理・フィルター
enabled フィルター機能を使うか
equalization ヒストグラム均等化（暗い場所でも見やすくする画像補正）
flip 映像の左右反転（鏡表示）
face：顔の検出と分析
enabled 顔解析全体を使うか
detector 顔検出の設定全体。傾き補正はその中の rotation
mesh 顔の立体構造（468箇所の網目状キーポイント）を追跡
attention 目・唇まわりの点を細かくする別モデル（facemesh-attention）に切り替えるか
iris 黒目（虹彩）の位置や大きさをピンポイントで分析
description 年齢や性別の判定、顔の特徴量抽出
emotion 感情の予測（喜怒哀楽など）
antispoof 作り物の顔（CGなど）でないかをrealという点数で返す
liveness 録画の再生（スマホ画面に映した顔など）でないかをliveという点数で返す
その他の検出モジュール
body 姿勢・骨格トラッキング
hand 手・指のトラッキング
object 日常品などの物体検出
segmentation 人物と背景の切り分け・背景透過
gesture ジェスチャーを認識

コード例

パターン / 方式 特徴 ポイント
1. Promise
（非同期処理の古典的な書き方）		 .then() を使って「検出が終わったら描画する」を順番に実行する最も基礎的な書き方です。 human.draw.face や human.draw.hand のように、描画したいパーツを1つずつ個別に指定して描画しています。
2. async / await
（モダンでシンプルな書き方）		 初心者におすすめの基本形です。 async/await を使うことでコードがすっきり読みやすくなります。また、human.draw.all() を使うことで顔・手・体などの全検出結果を1行でまとめて描画しています。
3. イベント
（処理完了の通知を受け取る書き方）		 検出処理と描画処理のタイミングを完全に切り離す書き方です。 human.events.addEventListener('detect', ...) を設定しておくことで、AIの検出が完了した瞬間に自動で描画処理が呼ばれます。
※ここから下は、映像をよりヌルヌル（滑らか）に動かすための発展パターンです。
4. 検出ループと描画ループの分離
（滑らかさUP）		 「AIの計算」と「画面の描画」を別々に同じスレッドで交互に動きます。 AIの検出結果は少し遅れて届くため、そのまま描画すると線がカクつきます。human.next(result) を使うことで、検出結果のコマとコマの間を前回の結果と新しい結果を経過時間に応じて混ぜる計算（スムージング）をし、ヌルヌルと滑らかに描画させます。
5. human.video()
（手動ループの省略）		 パターン4の「検出ループ」をライブラリ内部に任せて、より短く書く方法です。 自分で detect() を何度も呼び出すコードを書かなくても、human.video(inputVideo) を1行呼ぶだけで内部で自動的にカメラ検出を回し続けてくれます。
6. human.webcam ヘルパー
（カメラ起動も全自動）		 Webカメラの起動から映像取得まで全自動で行う最もラクな書き方です。 HTML側に <video> タグを用意する必要すらありません。await human.webcam.start() を呼ぶだけでカメラを起動し、そのまま検出・描画まで繋いでくれます。

デフォルトモデル

このアプリが使うのは BlazeFace・FaceMesh・FaceRes の3つ

デフォルトモデル 機能
顔の検出
MediaPipe BlazeFace		 画面内から顔の位置（四角い枠）を高速で見つける
顔の立体メッシュ
MediaPipe FaceMesh		 顔の表面に 468 箇所のキーポイントを割り当て、立体形状を把握する
目の虹彩分析
MediaPipe Iris		 黒目の位置や瞳孔の動き、視線を精度高く捉える
顔の属性推定
HSE FaceRes		 年齢や性別、顔の特徴量（照合用データ）を抽出する
感情の検出
Oarriaga Emotion		 表情から喜怒哀楽（Happy, Sad, Angry など）を判定する
身体ポーズ追跡
MoveNet (Lightning)		 人物の骨格（頭、肩、肘、膝など）を高速に追跡する
手・指の追跡
HandTrack / MediaPipe		 手のひらや指先（21箇所の関節）の動きを立体的に分析する
背景切り抜き
Google Selfie		 人物と背景を自動で切り分け、背景ボカシなどに使う
物体検出
CenterNet		 日常の物体（スマホ、コップ、椅子など）を見つける
