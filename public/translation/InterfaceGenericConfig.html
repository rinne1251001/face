このアプリの使用モジュール

モジュール enabled modelPath 入力サイズ
face.detector true blazeface.json 256×256
face.mesh true facemesh.json 192×192
face.description true faceres.json（照合用の特徴量） 224×224 → 1024次元

①FaceDetector：画面内のどこに顔があるか探す（四角枠）
②FaceMesh：顔の立体形状・パーツ位置を把握する（468点）
③FaceDescription：顔画像から1024個の特徴量を生成する

入力サイズはpublic/models/human/*.jsonの中に書かれている
[1, 256, 256, 3]→256×256の画像を1枚、[-1, 192, 192, 3]→192×192の画像を何枚でも、[-1, 224, 224, 3]→224×224の画像を何枚でも、[1, 1024]→1枚につき1024個の数値 = 特徴量

各型の役割
「同梱なし」は、npmのパッケージの models/ フォルダに入っていないモデルで、使うには別リポジトリ(vladmandic/human-models)から取ってくる必要

import { Human } from '@vladmandic/human';

②指定した設定でHumanの実体（インスタンス）を生成

face.emotion.enabled true false
body.enabled true false
hand.enabled true false 
const human = new Human({
