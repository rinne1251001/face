Human 顔認識: FaceID

FaceID は、顔の照合を実行する前に複数のチェックを行い、Webカメラ入力を検証します。
検出された顔画像および記述子（descriptor）は、クライアント側の IndexedDB に保存されます。

ワークフロー

  1. Webカメラを起動します。
  2. 入力動画に検証済みの顔が含まれるか、タイムアウトに達するまで待機します：
    • 人数
    • 顔のサイズ
    • 顔および視線の方向
    • 検出スコア
    • ライブ入力であることを確認するための「まばたき検出」（まばたきの速度の時系列チェックを含む）
    • オプションの「なりすまし防止（Anti-spoofing）」モジュールを実行します。
    • オプションの「生体検知（Liveness）」モジュールを実行します。
  3. 登録済みの顔データベースに対して照合を実行し、スコアとともに最適な照合結果を表示します。

補足

なりすまし防止モデルと生体検知モデルはどちらも非常に軽量であり、他の指標と組み合わせて迅速なチェックを行うよう設計されています：

  • モデルサイズは 1MB 未満
  • 非常にシンプルなため推論時間が極めて高速（なりすまし防止は11演算、生体検知は23演算）
  • 低解像度入力で学習済み

なりすまし防止モジュール (Anti-spoofing Module)

  • 入力が本物の顔であるか（例：コンピュータ生成された顔ではないか）をチェックします
  • 設定: human.config.face.antispoof.enabled
  • 結果: human.result.face[0].real（スコアとして取得）

生体検知モジュール (Liveness Module)

  • 録画による明らかなアーティファクト（例：スマートフォンの画面で再生された顔の動画など）が入力に含まれていないかをチェックします
  • 設定: human.config.face.liveness.enabled
  • 結果: human.result.face[0].live（スコアとして取得）

モデル (Models)

FaceID は以下のモデルと互換性があります：

  • faceres.json（デフォルト）: 年齢 / 性別 / 記述子の複合解析を行います。
  • faceres-deep.json: faceres の高解像度バリエーションです。
  • insightface: 顔記述子解析用の代替モデルです。
  • mobilefacenet: 顔記述子解析用の代替モデルです。

注

FaceIDとはHumanライブラリの顔認証機能を搭載したでもアプリです

Face IDデモ このアプリ
特徴量・顔写真の保存先 ブラウザの IndexedDB（その端末だけ） サーバーの MySQL と storage/app/private
照合する場所 ブラウザ（human.match.find） サーバー（FaceMatcher）
似ている度合い 距離をもとにした類似度、しきい値 0.5 コサイン類似度、しきい値 0.6 ＋ margin 0.05
まばたきチェック あり なし
antispoof / liveness オン オフ
iris（視線の向き） オン オフ

照合に使われる顔の特徴データ（記述子）を抽出して顔分析するモデルを選択可能

モデルファイル名 説明・特徴
faceres.json
（デフォルト）		 年齢・性別の判定と顔の照合をバランスよく同時に行います。
faceres-deep.json より高解像度で精度の高い解析を行うバージョン。
insightface / mobilefacenet 業界で広く使われている別の高度な顔照合AIモデルへ切り替えることも可能です。
