Human

Humanとは？

オープンソースのAIライブラリ（@vladmandic/human）で、TensorFlow.jsなどをベースにしている
顔検出・3D顔の向きの追跡（Face Detection & Rotation Tracking）、顔のメッシュ（特徴点）や虹彩（Iris）の検出、顔の記述・特徴量抽出（Face Description/Recognition）、身体のポーズ、手のジェスチャー、感情認識などをWebカメラから検出

faceresとは？

検出された顔から個性を数値化（特徴量ベクトル化）する
顔の画像から、その人固有のパターンを抽出し、AIが認識・比較できるデータ（顔埋め込み：Face Embedding）に変換

導入理由

①高精度な特徴量

Humanは特徴量を計算する前に、顔の切り出し → 傾きの補正 → 顔の細かい形（メッシュ）の検出 → もう一度傾きを補正 → 白黒に変換 → 明るさをそろえる、という処理をしている
→照明や顔の傾きの違いの影響を受けにくい。

②エッジ処理

ユーザーのPCやスマホのGPU/CPUを使ってブラウザ内で計算するため、Laravelサーバー側は軽量な数値データ（JSON）と画像を受け取って保存・検索するだけで済む
→サーバーに高価なGPUサーバーを用意する必要がなく、インフラコストを大幅に抑えられる

③通信量の小ささ

カメラ映像の全フレーム（動画）をサーバーに送信し続けるのではなく、ブラウザ上で顔が検出された瞬間の「特徴量（数値配列）」だけを送信
→通信量が非常に小さく、照合処理も爆速

④マルチバックエンド対応

GPUのある環境ではWebGL（GPU加速）を使って高速処理し、GPUのない環境では自動的にWASM（WebAssembly）によるCPU処理へ切り替わる
→動かないというトラブルを防ぐ

⑤アップデート

TypeScriptベースで記述されており、TensorFlow.js の最新エコシステムに追従して更新されている
→アーカイブされたface-api.jsと違い、Humanは2026年10月時点でまだ公開・保守されている。ただし作者1人の個人開発で、最新版3.3.6（2025年8月）以降は更新されておらず、更新頻度は高くない。 そのため、Humanを直接使うのはface-engine.js だけにして、将来ほかのライブラリに差し替えやすくしている。

⑥なりすまし防止

瞬きや視線・表情の動きなど生きている人間特有の動きを検知
→「他人の写真」や「スマホの画面」はブロックされる

なりすましを判定するモデル（antispoof、liveness）はこのアプリでは無効にしているため、現状は写真やスマホ画面でも認証が通る可能性がある。入退室管理など厳しい用途で使う場合は、有効にして効果を検証する必要がある。

⑦追加拡張の容易さ

基本機能だけでなく、開発者が自分の作りたいアプリに合わせて新しい機能や設定を簡単に追加・カスタマイズできるよう設計されている

照合の仕組み

大まかな流れ

①特徴量の長さを1にそろえる
②生徒ごとに一番似ている登録写真の類似度を取る
③1位がしきい値以上で、2位との差がmargin以上なら本人と判定する

①特徴量の長さを1にそろえる

特徴量(embedding)とは顔認証に使われるデータのことで、数値の配列になっています
例えば数値の個数が２個(2次元)なら[3, 4]、３個(3次元)なら[3, 4, 5]という形です
また、これをグラフにすると、[3, 4]は原点からx=3,y=4のところにあり、[3, 4, 5]はx=3,y=4,z=5のところにあります
そのため、特徴量は2人の顔がどれくらい似ているかを数学的・幾何学的に比べる「矢印の向き」として扱われます
Humanの数値の個数(次元数:dimension)は1024なので、このアプリでは1024次元の空間の点・矢印で顔認証をしています

矢印の長さは撮影条件などでも変わるので、長さを１に揃えてから矢印の向きを比べます
登録時に長さを1にしてからDBに保存しておけば、照合時には送られてきた1件だけを長さ1にするだけで顔認証が簡単にできます 

public static function toUnitVector(mixed $raw, string $field = 'embedding'): array
{
    // 配列でない、連想配列（リスト形式でない）、次元数（要素数）が設定範囲外なら終了
    $count = is_array($raw) ? count($raw) : 0;
    if (! is_array($raw) || ! array_is_list($raw) || $count < config('face.min_dimension') || $count > config('face.max_dimension')) {
        throw ValidationException::withMessages([$field => '特徴量の形式が正しくありません。']);
    }

    // すべての要素の二乗和を求める
    $sum = 0.0;
    foreach ($raw as $x) {
        if (! is_int($x) && ! is_float($x)) {
            throw ValidationException::withMessages([$field => '特徴量に数値以外が含まれています。']);
        }
        $sum += $x * $x;
    }
    if ($sum <= 0.0 || ! is_finite($sum)) {
        throw ValidationException::withMessages([$field => '特徴量が不正です。']);
    }

    // ルートをかぶせて実際のベクトルの長さに戻す
    $norm = sqrt($sum);

    // 特徴ベクトルを1にする（例：[3, 4]→[0.6, 0.8]のように同じ比率で三平方の定理で計算すると1になる）
    return array_map(fn ($x) => $x / $norm, $raw);
}

計算方法（L2正規化（単位ベクトル化））
例えば[3, 4]の2次元配列なら、

ベクトルの長さを求める
三平方の定理（ピタゴラスの定理）を使って、原点からその点までの直線距離（大きさ）を計算 		√(3² + 4²) = √25 = 5
各数値を長さで割る
すべての数値を求めた長さ（5）で割ることで、全体のバランスを保ったまま大きさを調整 		[3÷5, 4÷5] = [0.6, 0.8]
長さが1になっているか確認
新しくできた数値を二乗して足すと合計が必ず「1」になる 		0.6² + 0.8² = 0.36 + 0.64 = 1

②生徒ごとに一番似ている登録写真の類似度を取る

閾値

設定ファイル

config/face.php
変更したらphp artisan config:clearを実行
appフォルダなどで使うときはconfig('face.threshold')と使う

threshold

どのくらい似ていたかの数値（similarity：値は0～1）の合格ライン

margin

１番似ていた人と２番目に似ていた人との差がこの値以上ないなら判定保留にする

実験（帽子）

①ノーマル、ニット帽、キャップの同一人物三人を登録
marginは0.2前後になり、それぞれ識別された

②ノーマルのみを登録
ニット帽、キャップを被った時のsimilarityは0.75～0.8くらいになった

実験（マスク）

①マスクありのみ登録
マスクなしで照合したときsimilarityは0.5後半になった

①マスクなしのみ登録
マスクありで照合したときsimilarityは0.5前半になった

②マスクありなし両方を登録
marginは0.3くらいになった

const video = document.getElementById('video');
const overlay = document.getElementById('overlay');
const statusText = document.getElementById('status');
const nameInput = document.getElementById('nameInput');
const registerBtn = document.getElementById('registerBtn');

// AIモデルが置かれているURL（vladmandic版の公式モデル等）
const MODEL_URL = 'https://cdn.jsdelivr.net/gh/vladmandic/face-api/model/';

let labeledDescriptors = [];

// 初期化とモデルの読み込み
async function init() {
    statusText.innerText = 'AIモデルを読み込んでいます...';

    // 必要なモデルをロード
    await faceapi.nets.tinyFaceDetector.loadFromUri(MODEL_URL);
    await faceapi.nets.faceLandmark68TinyNet.loadFromUri(MODEL_URL);
    await faceapi.nets.faceRecognitionNet.loadFromUri(MODEL_URL);

    statusText.innerText = 'カメラを起動しています...';
    await startVideo();

    loadSavedFaces();
    registerBtn.disabled = false;
    statusText.innerText = '準備完了！';
}

// Webカメラの起動
function startVideo() {
    return new Promise((resolve, reject) => {
        navigator.mediaDevices.getUserMedia({ video: {} }, {}, {})
            .then(stream => {
                video.srcObject = stream;
                video.onloadedmetadata = () => {
                    resolve();
                };
            })
            .catch(err => {
                statusText.innerText = 'カメラの起動に失敗しました。';
                reject(err);
            });
    });
}

// 登録された顔データを localStorage から復元
function loadSavedFaces() {
    const saved = localStorage.getItem('face_database');
    if (saved) {
        const parsed = JSON.parse(saved);
        labeledDescriptors = parsed.map(item => {
            return new faceapi.LabeledFaceDescriptors(
                item.name,
                item.descriptors.map(d => new Float32Array(d))
            );
        });
    }
}

// 顔データの保存
function saveFacesToStorage() {
    const dataToSave = labeledDescriptors.map(ld => ({
        name: ld.label,
        descriptors: ld.descriptors.map(d => Array.from(d))
    }));
    localStorage.setItem('face_database', JSON.stringify(dataToSave));
}

// 「顔を登録する」ボタンを押したときの処理
registerBtn.addEventListener('click', async () => {
    const name = nameInput.value.trim();
    if (!name) {
        alert('名前を入力してください。');
        return;
    }

    statusText.innerText = `${name}さんの顔を検出中...`;

    // 現在の映像から顔と特徴量を抽出
    const detection = await faceapi.detectSingleFace(video, new faceapi.TinyFaceDetectorOptions()).withFaceLandmarks(true).withFaceDescriptor();

    if (!detection) {
        alert('顔が検出されませんでした。カメラにしっかり顔を向けてください。');
        statusText.innerText = '準備完了！';
        return;
    }

    // すでに登録されている名前があれば追加、なければ新規作成
    const existingIndex = labeledDescriptors.findIndex(ld => ld.label === name);
    if (existingIndex > -1) {
        labeledDescriptors[existingIndex].descriptors.push(detection.descriptor);
    } else {
        labeledDescriptors.push(new faceapi.LabeledFaceDescriptors(name, [detection.descriptor]));
    }

    saveFacesToStorage();
    alert(`${name}さんの顔を登録しました！`);
    nameInput.value = '';
    statusText.innerText = '準備完了！';
});

// カメラ映像の再生が始まったらリアルタイム認識を開始
video.addEventListener('play', () => {
    const displaySize = { width: video.width, height: video.height };
    faceapi.matchDimensions(overlay, displaySize);

    setInterval(async () => {
        if (labeledDescriptors.length === 0) return;

        // 映像から複数の顔を検出・特徴量抽出
        const detections = await faceapi.detectAllFaces(video, new faceapi.TinyFaceDetectorOptions()).withFaceLandmarks(true).withFaceDescriptors();
        const resizedDetections = faceapi.resizeResults(detections, displaySize);

        const ctx = overlay.getContext('2d');
        ctx.clearRect(0, 0, overlay.width, overlay.height);

        // 登録データと照合するためのmatcherを作成（しきい値0.55）
        const faceMatcher = new faceapi.FaceMatcher(labeledDescriptors, 0.55);

        resizedDetections.forEach(detection => {
            const bestMatch = faceMatcher.findBestMatch(detection.descriptor);
            const box = detection.detection.box;

            const drawBox = new faceapi.draw.DrawBox(box, {
                label: `${bestMatch.label} (${Math.round(bestMatch.distance * 100) / 100})`
            });
            drawBox.draw(overlay);

            // 未知の人でなければ、ここで「出席処理」などをつなげることができます
            if (bestMatch.label !== 'unknown') {
                // 例：コンソールに記録
                // console.log(`${bestMatch.label} を検出しました`);
            }
        });
    }, 200);
});

// 実行開始
init();

次元数

次元数とは何個の数値で顔を表すか」の箱の数、そのデータが「いくつ項目を持っているか」の数
次元数が多いほど顔の違いの表現の幅が広がるが、＝精度が高いというわけではない

128次元 1024次元（Human）
1人の顔を表す数値の個数 128個 1024個
主な例 face-api.js、dlib Human（faceres）
顔の違いを表せる余地 小さい 大きい（128次元の8倍）
精度 次元数では決まらない。face-api.jsは128次元で、顔照合の標準テスト（LFW）の正解率は99.38%（公式発表） 次元数では決まらない。このアプリでの精度は自分たちの実験で確かめる
1枚分のデータ量（32bitの数値） 約0.5KB 約4KB
DBに保存したときの大きさ（JSONの文字列） 約2.5KB 約20KB
1回の照合の計算量 1とすると 約8倍
照合1回でサーバーに送るデータ 約2.5KB 約20KB
メリット ・保存・通信・計算がすべて軽い
・登録人数が増えても照合が速い
・DBや照合用キャッシュが小さく済む 		・顔の細かい違いを表せる余地が大きい（モデルがうまく学習できていれば、似た顔を区別する助けになる）
デメリット ・表せる余地が小さい（ただし、よく学習されたモデルなら128次元でも十分に高精度） ・データ量と計算量が約8倍
・DBと照合用キャッシュが大きくなる（例：1000人×5枚で、DBは約100MB、キャッシュは約20MB）
・余地が大きくても、モデルがそれを使い切っているとは限らない
