テーブル確認方法

XAMPPのShellで、

mysql -u root
use face;
show tables;　//テーブル一覧
SELECT * FROM テーブル名;　//テーブルの中身

もしくは、VS Codeのターミナルで、

php artisan db:table students

テーブル作成

VS Codeのターミナルで、

php artisan migrate　//新規
php artisan migrate:fresh　//作り直し

テストデータ注入

VS Codeのターミナルで、

php artisan db:seed

テーブルリセット＆データ注入を同時にするコマンド

php artisan migrate:fresh --seed

ログインIDやパスワード

databases/seedersのAdminSeeder.php、TeacherSeeder.phpに書いてある

teachers

先生の情報をまとめたテーブル

id ID
login_id ログインID
password パスワード
name 教師の名前
remember_token ログインし続けるか
created_at 作成日
updated_at 更新日

admins

システム管理者の情報をまとめたテーブル

id ID
login_id ログインID
password パスワード
remember_token ログインし続けるか
created_at 作成日
updated_at 更新日

登録するときはVS Codeのターミナルで、

php artisan tinker
> use App\Models\Admin;
> Admin::all()
> $a1 = new Admin()
> $a1->login_id = 1
> $a1->password = '12345678'
> $a1->save()

school_classes

クラスの情報をまとめたテーブル

id ID
name クラス名
created_at 作成日
updated_at 更新日

students

登録者（学生）の情報をまとめたテーブル

id ID
name 名前
student_number 学籍番号
school_class_id クラス名
is_active 照合の対象にするか（1=有効、0=停止）
created_at 作成日
updated_at 更新日

subjects

授業の情報をまとめたテーブル

id ID
name 授業名
day_of_week 開講曜日
period_start 開始時間
period_end 終了時間
created_at 作成日
updated_at 更新日

face_samples

顔認証用の顔写真テーブル

id ID
student_id studentsテーブル紐付けられている人物のID
image_path 保存先（faces/(student_id)/～.jpg）
embedding AIが顔の画像から作る1024個の数値の並び
並び全体でその人の顔を表し、矢印の向き（コサイン類似度）で似ているかを判断する
dimension 特徴量の数値の個数（次元数）
Humanのfaceresでは1024
model_version Humanのバージョン情報（human-3.3.6-faceres）
created_at 作成日
updated_at 更新日

match_logs

「誰が・いつ・どのような判定結果で顔認証を行ったか」という監査履歴（ログ）を保存

id ID
student_id studentsテーブル紐付けられている人物のID
判定に合格しなかったときも、一番似ていた生徒のIDが入る
similarity どれだけ似ているか（0~1）
margin ２番目に似ていた人との差
accepted 成功したか（0 or 1）
model_version Humanのバージョン情報（human-3.3.6-faceres）
teacher_id 出席受付をした教師
照合テストでは空
created_at 作成日

データベースに照合結果を保存する理由
①不正アクセスやなりすましを追跡しやすい
②システムの運用基準を最適化するデータとして活用できる
③モデルバージョン変更時の互換性チェック

pivot

中間テーブル3つ

school_class_teacher

教師が受け持つクラスの情報をまとめたテーブル

school_class_id クラスのID
teacher_id 教師のID

student_subject

生徒が受講する授業の情報をまとめたテーブル

student_id 学生のID
subject_id 授業のID

subject_teacher

教師が担当する授業の情報をまとめたテーブル

subject_id 授業のID
teacher_id 教師のID

attendances

出席情報をまとめたテーブル

id ID
student_id 学生ID
subject_id 授業のID
date 授業日
status present（出席）/ late（遅刻）/ absent（欠席）
method face（顔認証）/ manual（教師が手動で登録）
match_log_id 顔認証のときの照合記録
teacher_id 手動で登録した教師
created_at 登録日
updated_at 更新日
