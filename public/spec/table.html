テーブル確認方法

XAMPPのShellで、

mysql -u root
use face;
show tables;　//テーブル一覧
SELECT * FROM テーブル名;　//テーブルの中身

テーブル作成

VS Codeのターミナルで、

php artisan migrate　//新規
php artisan migrate:fresh　//作り直し

テーブル作成

VS Codeのターミナルで、

php artisan db:seed

ログインIDやパスワード

databases/seedersのAdminSeeder.php、TeacherSeeder.phpに書いてある

admins

システム管理者の情報をまとめたテーブル

id ID
login_id ログインID
password パスワード
remember_token ログインし続けるか
created_at 作成日
updated_at 更新日

登録するときはVS Codeのターミナルで、

php artisan tinker
> use App\Models\Admin;
> Admin::all()
> $a1 = new Admin()
> $a1->login_id = 1
> $a1->password = 12345678
> $a1->save()

face_samples

顔認証用の顔写真テーブル

id ID
student_id studentsテーブル紐付けられている人物のID
image_path 保存先（faces/(student_id)/～.jpg）
embedding 顔の特徴量の数値の配列
AIが顔写真から抽出した「顔の形や各パーツの位置関係」を数値化したもの
dimension 特徴量データ（embedding）の次元数
Humanなので1024のチェック項目で確認
model_version Humanのバージョン情報（human-3.3.6-faceres）
created_at 作成日
updated_at 更新日

match_logs

「誰が・いつ・どのような判定結果で顔認証を行ったか」という監査履歴（ログ）を保存

id ID
student_id studentsテーブル紐付けられている人物のID
similarity どれだけ似ているか（0~1）
margin ２番目に似ていた人との差
accepted 成功したか（0 or 1）
model_version Humanのバージョン情報（human-3.3.6-faceres）
created_at 作成日
updated_at 更新日

データベースに照合結果を保存する理由
①不正アクセスやなりすましを追跡しやすい
②システムの運用基準を最適化するデータとして活用できる
③モデルバージョン変更時の互換性チェック
