github

githubの上げ方

①ソース管理(Ctrl+Shift+G)を開く
②「コミット」の下にある変更の「＋」ボタンを押す
③メッセージに好きな言葉を入力
④「コミット」を押す
⑤「変更を同期」or「プッシュ」を押す

他のメンバーが更新したgithubの内容を確認・取得する

① ソース管理(Ctrl+Shift+G)を開く
② 「すべてのリモートからフェッチ」を押すと、最新の更新内容を確認できる
③ 「プル」を押すと、最新の変更を手元の環境にダウンロードできる

データベース＆テーブル

データベースを作る方法

①XAMPP起動
②MySQLをstart
③Shellをタップし以下のコマンドを打つ 

mysql -u root　//MySQLにログイン
CREATE DATABASE face;　//faceという名前のデータベースを作成
SHOW DATABASES;　//データベース一覧のコマンド。faceがあれば成功

どのデータベースを使うかは、.envファイルに書いてあります

DB_DATABASE=face

テーブルを作る方法

VS Codeのターミナルを開いて以下のコマンドを打つ

php artisan migrate

テーブルの内容はdatabase/migrationsにあるファイルに書いてあり、１つのファイルにつき１つ以上のテーブルが作成されます
（例：2026_09_28_000001_create_admins_table.php→adminsテーブル）

⚠️一度php artisan migrateをやったマイグレーションファイルは更新してもテーブルには反映されません
そのため、以下のコマンドを打つ必要があります（データベースに登録したデータは全て削除され作り直しになるので注意） 

php artisan migrate:fresh　//テーブル作り直し
Remove-Item -Recurse -Force storage/app/private/faces　//顔写真削除
php artisan cache:clear　//古い特徴量キャッシュをクリア

ビュー

ファイルの場所

resources/viewsフォルダにあるbladeファイルです

レイアウト

全てのファイルで共通するレイアウト(ヘッダーやフッターなど)はresources/views/layouts/app.blade.phpファイルで作成されています
このレイアウトを使いたい時は以下の形式で書きます 

@extends('layouts.app')
@section('title', 'タイトル名')　//省略ok（その場合は「顔認識システム」というタイトルになる）
@section('content')

//ここに中身を書いていく

@endsection

なお、scriptを書きたい時は以下の形式になります

@extends('layouts.app')
@section('title', 'タイトル名')
@section('content')

//ここに中身を書いていく

@endsection
@push('scripts')
<script>

//ここにスクリプトを書いていく

</script>
@endpush

新しいレイアウトファイル作って使いたいときは、@extends('layouts.app')を@extends('layouts.ファイル名')にすると使えます
例：layouts/cute.blade.phpなら@extends('layouts.cute')

ルーティング

Laravelではファイルを作っただけではファイルは見れません
そのため、resources/views/〇〇.blade.phpを作ったらroutes/web.phpに書き込む必要があります
ルーティングの書き方はviewのみの場合とコントローラーも使う場合の２種類あります

viewのみ

ビュー（ページの表示）を返すだけのとき

Route::view('/URL名', 'ファイルの場所')->name('名前付きルート');

例：Route::view('/url', 'folder/file')->name('name');なら、
URLはhttp://127.0.0.1:8000/url、
ファイルの場所はresources/views/folder/file.blade.php、
このファイルに遷移したい時は<a href="{{ route('name') }}">になる

view＆controller

ビュー（例：resources/views/articles）とコントローラー（例：app/Http/Controllers/ArticleController）を返すとき

use App\Http\Controllers\コントローラー名;

Route::HTTPメソッド('/URL名', [コントローラー名::class, 'クラス名'])->name('名前付きルート');

例：Route::get('/articles', [ArticleController::class, 'index'])->name('articles.index');なら、
HTTPメソッドはget
URLはhttp://127.0.0.1:8000/articles、
コントローラーはapp\Http\Controllers\ArticleController.phpのindex()メソッド、
このファイルに遷移したい時は<a href="{{ route('articles.index') }}">になる

主なHTTPメソッド

HTTP 説明 アクション ルーティング
GET① データの取得 index()、create() Route::get('/url名', ...)
GET② データの取得 show()、edit() Route::get('/url名/{id}', ...)
Route::get('/url名/{id}/edit', ...)
POST データの新規作成 store() Route::post('/url名', ...)
PATCH データの更新 update() Route::patch('/url名/{id}', ...)
DELETE データの削除 destroy() Route::delete('/url名/{id}', ...)
