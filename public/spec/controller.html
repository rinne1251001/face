コントローラーファイルの形式

コントローラーファイルとはユーザーからのリクエストを受け取ってモデル（データ処理）とビュー（画面表示）に橋渡しするファイルのこと

ファットコントローラー（文量がめちゃくちゃあること）は読みにくく嫌われるので、メソッドを分割したり、Servicesフォルダに処理を移しましょう

コントローラーの形式

<?php

namespace App\Http\Controllers\フォルダ名;  // 例：Admin/FaceMatchController.phpなら「Admin」

// 必要なクラスや機能をインポートする
use App\Http\Controllers\Controller;
use Illuminate\Http\Request;
use Illuminate\Http\RedirectResponse;
use Illuminate\View\View;

// クラス宣言
class ファイル名 extends Controller
{
    // 一覧画面
    public function index(): View
    {
        //
    }

    public function create(): View
    {
        //

    // 新規作成保存処理
    public function store(Request $request): RedirectResponse
    {
        //
    }

    // 詳細画面
    public function show(string $id): View
    {
        //
    }

    // 編集画面
    public function edit(string $id): View
    {
        //
    }

    // 編集保存処理
    public function update(Request $request, string $id): RedirectResponse

    {

    }

    // 自分で作った名前のメソッド
    public function 〇〇()

このアプリで使っているuse文

use文とは？

use文は必要なクラスや機能をインポートするために書きます
他の名前空間（フォルダ）にある場合に書き、同じフォルダにある場合は書かなくても構いません
例：Controllers/Admin/FaceMatchController.phpはuse App\Http\Controllers\Controller;を書かないとエラーになるが、Controllers/PhotoControllerなら書かなくてもok

基底コントローラー

App\Http\Controllers\Controller

Laravelのすべてのコントローラーが継承する「親クラス（基底コントローラー）」
共通処理を書くための置き場所

リクエストとレスポンス関連

Illuminate\Http\Request

ユーザーが送信したデータ（フォームの入力値、クエリパラメータ、ヘッダー情報など）を受け取る

Illuminate\Http\JsonResponse

データをJSON形式（APIのレスポンスなど）で返す

Illuminate\Http\RedirectResponse

処理が終わった後に別のURLやページへリダイレクト（転送）

Symfony\Component\HttpFoundation\StreamedResponse

大量のデータや重いファイル（CSVダウンロードなど）を、メモリを節約しながら少しずつクライアントにストリーミング送信

データベース・認証・ストレージ関連

Illuminate\Support\Facades\DB

データベース操作用ファサード
SQLを直接実行したり、高度なクエリを組み立てたりする 

Illuminate\Support\Facades\Auth

認証用ファサード
現在ログインしているユーザーの情報を取得したり、ログイン・ログアウトの処理を行ったりする 

Illuminate\Support\Facades\Storage

ファイルストレージ用ファサード
画像やPDFなどのファイルをサーバーやクラウド（S3など）に保存・削除・読み込みする

ユーティリティ（便利機能）関連

Illuminate\Support\Carbon

PHP標準の日付・時刻操作（DateTime）をより強力で直感的に扱えるように拡張した、日時操作ライブラリ

Illuminate\Support\Str

文字列を操作・加工する便利なメソッド集
ランダムな文字列の生成、スラッグ化、文字の切り詰めなど

バリデーション（入力チェック）関連

Illuminate\Validation\Rule

バリデーションルールを複雑に定義・カスタマイズするためのクラス

Illuminate\Validation\ValidationException

バリデーション（入力チェック）に失敗したときに発生する例外（エラー）を扱うクラス

画面表示関連

Illuminate\View\View

画面（ビュー）を返却・操作するためのクラス

JsonResponse

データをJSON形式で返す Javascriptに返して非同期処理をするときなどに使う 

return response()->json([
    'saved' => count($prepared),
    'total' => $student->faceSamples()->count(),
]);

RedirectResponse

処理終了後に別のページへリダイレクト

// 指定したURLへ直でリダイレクト
return redirect()->route('admin.login');

// intendedはログインしていない人が開こうとしたページを覚えておきログイン後にそこへ戻す。覚えたページがなければ引数のページへリダイレクト
return redirect()->intended(route('admin.students.index'));

// 直前のページへリダイレクト
return back();

// withはメッセージを付けてリダイレクト
return redirect()->route('admin.classes.index')->with('status', '削除しました。');

StreamedResponse

データサイズが非常に大きい重いファイルをメモリを圧迫しないように少しずつ分割して送信

return Storage::disk('local')->response($faceSample->image_path, null, [
    'Cache-Control' => 'private, no-store',
]);

/**
 * Storage::disk('local')：storage/app/private
 * response：指定したパスにあるファイルをブラウザへファイルデータそのものとして送信、画面を表示する代わりに画像ファイルのバイナリデータをそのまま返す
 * private：ブラウザ以外にキャッシュしない
 * no-store：ブラウザの履歴やキャッシュ領域にデータを保存しない
 */

string

純粋な文字列を返す

return '文字';

array

配列を返す

return [$data, $subjectIds];

Request $request

public function store(Request $request)
{
    //  「title」という名前の入力値を取得する
    $body = $request->title; 

    // 「image」というファイルや項目が送信されてきているか？
    if ($request->hasFile('image')) {
        //
    }

    // バリデーションチェック
    $validated = $request->validate([
        'title' => 'required|max:255',
        'body' => 'required',
    ]);

    // フォームに入力したすべてのデータを配列で取得し、データベース（Postテーブル）に一括保存
    $allData = $request->all();
    Post::create($allData);
}

「Request $request」はユーザーがWebブラウザから送信したデータ（フォームの入力値、URLのパラメータ、ヘッダー情報など）をコントローラーで受け取ります
※use Illuminate\Http\Request;がないとエラーになります

public function store(Request $request): RedirectResponse
{
    // バリデーションチェック
    $validated = $request->validate([
        'name' => ['required', 'string', 'max:100'],
        'day_of_week' => ['required', 'integer', Rule::in(array_keys(Subject::DAYS))],
        'period_start' => ['required', 'integer', 'between:1,'.Subject::MAX_PERIOD],
        'period_end' => ['required', 'integer', 'between:1,'.Subject::MAX_PERIOD, 'gte:period_start'],
        'start_date' => ['nullable', 'date'],
        'end_date' => ['nullable', 'date', 'after_or_equal:start_date'],
    ], [], [
        'name' => '授業名',
        'day_of_week' => '曜日',
        'period_start' => '開始時限',
        'period_end' => '終了時限',
        'start_date' => '開始日',
        'end_date' => '終了日',
    ]);

    // subjectテーブルにデータを保存
    $subject = Subject::create($validated);

    // 処理が完了したらtests.indexにリダイレクト
    // view()はビューファイルのパスだけど、route()はルート名を書く
    return redirect()->route('tests.index');
}

バリデーションチェック

書き方

$request->validate～と書いて入力値をチェック
２つ目と３つ目の配列は省略可

$data = $request->validate(
    [
        // チェック項目とルール
        'students' => ['required', 'array', 'max:200'],
        'students.*.student_number' => ['required', 'string'],
    ], 
    [
        // カスタムエラーメッセージ（特定のルールに違反したときに表示するエラー文）
        'students.required' => '名前と学籍番号を1人分以上入力してください。',
        'students.*.student_number.distinct' => ':position行目の学籍番号が重複しています。',
    ], 
    [
        // カスタム属性名（エラー文に表示する置き換え用テキスト）
        'students' => '生徒',
        'students.*.name' => ':position行目の名前',
    ]
);

バリデーションルール

ルールは|で繋ぐか、配列形式で複数指定できる

ルール 意味
required 必須項目
nullable 空でok
string 文字列
array 配列
numeric 数値
integer 整数
max:値 指定した文字数、数値、配列の個数、ファイルのKB以下
min:値 指定した文字数、数値、配列の個数、ファイルのKB以上
email 有効なメールアドレス形式
unique:テーブル名,カラム名 テーブルのカラムの値と重複していない
exists:テーブル名,カラム 指定したカラムにその値が存在する
distinct 配列の中に重複した値がない
distinct:strict 配列内で値がデータ型も含めて重複していない
between:最小値,最大値 最小値以上最大値以下
gte:他のカラム名 指定した他のカラム以上の値
gt:他のカラム名 指定した他のカラムより大きい値
date_format:Y-m-d 指定した日付フォーマット（例: 2026-06-06）であること
before_or_equal:today 今日以前の日付
Rule::in([config('ファイル名.値')]) 指定した設定ファイル内の値と同じ
Rule::unique('テーブル名')->ignore($モデル名) 自分以外でテーブル内の値が重複していない
Rule::in([...array_keys(モデル名::定数)]) 指定したモデルの定数のいずれかの値

メソッドチェーン

データベース操作（Eloquentクエリビルダ）

where() データを絞り込む
例：where('status', 'active')、where('age', '>=', 20)、where('name', 'LIKE', '%田中%')
with(リレーション名) 関連テーブルも取得
例：with('students')
get() 全て取得
first() 最初の一件のみ取得
orderBy(列) 指定した列で並び替え
paginate(数字) 指定した数字でページネーション

リダイレクトとフラッシュメッセージ

redirect()->route('ルート名') 指定したURLへリダイレクト
redirect()->back() 前のページに戻る
->with('キー', 'メッセージ') 一時的なメッセージを渡す
->withInput() 入力内容保持
->withErrors(内容) エラーを次の画面に渡す
ビューの $errors に入る

コレクションの操作（取得したデータの加工）

->sortBy('カラム名') 指定したカラムで並び替え
->pluck('カラム名') 指定したカラムのみ抽出
->filter(fn($item) => ...) 条件に合うものだけ抽出
->map(function($item) { ... }) 新しいデータ構造に変換
->values() コレクションの添字を0から始まる連番に振り直す
