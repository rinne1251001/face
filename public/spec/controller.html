コントローラーファイルの形式

コントローラーファイルとはユーザーからのリクエストを受け取ってモデル（データ処理）とビュー（画面表示）に橋渡しするファイルのことです

コントローラーの形式

namespace App\Http\Controllers\フォルダ名;  // 例：Admin/FaceMatchController.phpなら「Admin」

// 必要なクラスや機能をインポートする
use App\Http\Controllers\Controller;
use Illuminate\Http\Request;

// クラス宣言
class SettingController extends Controller
{
    // 一覧画面
    public function index()
    {
        //
    }

    // 新規作成画面
    public function create()
    {
        //
    }

    // 新規作成保存処理
    public function store(Request $request)
    {
        //
    }

    // 詳細画面
    public function show(string $id)
    {
        //
    }

    // 編集画面
    public function edit(string $id)
    {
        //
    }

    // 編集保存処理
    public function update(Request $request, string $id)
    {
        //
    }

    // 削除処理
    public function destroy(string $id)
    {
        //
    }

    // 自分で作った名前のメソッド
    public function 〇〇()
    {
        //
    }
}

このアプリで使っているuse文

use文とは？

use文は必要なクラスや機能をインポートするために書きます
他の名前空間（フォルダ）にある場合に書き、同じフォルダにある場合は書かなくても構いません
例：Controllers/Admin/FaceMatchController.phpはuse App\Http\Controllers\Controller;を書かないとエラーになるが、Controllers/PhotoControllerなら書かなくてもok

基底コントローラー

App\Http\Controllers\Controller

Laravelのすべてのコントローラーが継承する「親クラス（基底コントローラー）」
共通処理を書くための置き場所

リクエストとレスポンス関連

Illuminate\Http\Request

ユーザーが送信したデータ（フォームの入力値、クエリパラメータ、ヘッダー情報など）を受け取る

Illuminate\Http\JsonResponse

データをJSON形式（APIのレスポンスなど）で返す

Illuminate\Http\RedirectResponse

処理が終わった後に別のURLやページへリダイレクト（転送）

Symfony\Component\HttpFoundation\StreamedResponse

大量のデータや重いファイル（CSVダウンロードなど）を、メモリを節約しながら少しずつクライアントにストリーミング送信

データベース・認証・ストレージ関連

Illuminate\Support\Facades\DB

データベース操作用ファサード
SQLを直接実行したり、高度なクエリを組み立てたりする 

Illuminate\Support\Facades\Auth

認証用ファサード
現在ログインしているユーザーの情報を取得したり、ログイン・ログアウトの処理を行ったりする 

Illuminate\Support\Facades\Storage

ファイルストレージ用ファサード
画像やPDFなどのファイルをサーバーやクラウド（S3など）に保存・削除・読み込みする

ユーティリティ（便利機能）関連

Illuminate\Support\Carbon

PHP標準の日付・時刻操作（DateTime）をより強力で直感的に扱えるように拡張した、日時操作ライブラリ

Illuminate\Support\Str

文字列を操作・加工する便利なメソッド集
ランダムな文字列の生成、スラッグ化、文字の切り詰めなど

バリデーション（入力チェック）関連

Illuminate\Validation\Rule

バリデーションルールを複雑に定義・カスタマイズするためのクラス

Illuminate\Validation\ValidationException

バリデーション（入力チェック）に失敗したときに発生する例外（エラー）を扱うクラス

画面表示関連

Illuminate\View\View

画面（ビュー）を返却・操作するためのクラス

戻り値の型

戻り値の型宣言

public function index(): Viewの「: View」はメソッドがどの型を返すのかを宣言するものです
一目でメソッドの戻り値の型が分かる＆IDEサポートの強くなるのでこのアプリでは必ず書いてください

View

ビューを表示する

// データを渡さず画面表示のみ
return view('teacher.settings.index');

// 変数を渡す＆画面表示
return view('admin.classes.index', compact('classes'));

// 連想配列で細かくデータを渡す＆画面表示
return view('auth.login', [
    'title' => '管理者ログイン',
    'action' => route('admin.login'),
    'otherLink' => ['label' => '教師の方はこちら', 'url' => route('teacher.login')],
]);

JsonResponse

データをJSON形式で返す Javascriptに返して非同期処理をするときなどに使う 

return response()->json([
    'saved' => count($prepared),
    'total' => $student->faceSamples()->count(),
]);

RedirectResponse

処理終了後に別のページへリダイレクト

// 指定したURLへ直でリダイレクト
return redirect()->route('admin.login');

// intendedはログインしていない人が開こうとしたページを覚えておきログイン後にそこへ戻す。覚えたページがなければ引数のページへリダイレクト
return redirect()->intended(route('admin.students.index'));

// 直前のページへリダイレクト
return back();

// withはメッセージを付けてリダイレクト
return redirect()->route('admin.classes.index')->with('status', '削除しました。');

StreamedResponse

データサイズが非常に大きい重いファイルをメモリを圧迫しないように少しずつ分割して送信

return Storage::disk('local')->response($faceSample->image_path, null, [
    'Cache-Control' => 'private, no-store',
]);

/**
 * Storage::disk('local')：storage/app/private
 * response：指定したパスにあるファイルをブラウザへファイルデータそのものとして送信、画面を表示する代わりに画像ファイルのバイナリデータをそのまま返す
 * private：ブラウザ以外にキャッシュしない
 * no-store：ブラウザの履歴やキャッシュ領域にデータを保存しない
 */

string

純粋な文字列を返す

return '文字';

array

配列を返す

return [$data, $subjectIds];

メソッド

メソッドの引数（パラメータ）

ルートモデルバインディング

public function show(Subject $subject): View
{
    /**
     * subjectsテーブルからルートパラメータのIDのデータ1件が入った$subjectという変数と一緒にビューを表示する
     * ルートパラメータとはhttp://127.0.0.1:8000/subjects/1の「1」、ルーティングで{subject}と表現されるもの
     */
    return view('subjects.show', compact('subject'));
}

自動的にデータベースからルートパラメータのIDのデータを持ってきてくれる書き方
該当データがなければ404を表示
※使うテーブルのモデルをuse文に書かないとエラーになります

Request $request

public function store(Request $request)
{
    //  「title」という名前の入力値を取得する
    $body = $request->title; 

    // フォームに入力したすべてのデータを配列で取得し、データベース（Postテーブル）に一括保存
    $allData = $request->all();
    Post::create($allData);

    // 「image」というファイルや項目が送信されてきているか？
    if ($request->hasFile('image')) {
        //
    }

    // バリデーションチェック
    $validated = $request->validate([
        'title' => 'required|max:255',
        'body' => 'required',
    ]);
}

「Request $request」はユーザーがWebブラウザから送信したデータ（フォームの入力値、URLのパラメータ、ヘッダー情報など）をコントローラーで受け取ります
※use Illuminate\Http\Request;がないとエラーになります

CRUDメソッド

メソッド名 役割 ビューの有無 ルート
index 一覧表示 〇 
Route::get('/students', [StudentController::class, 'index'])->name('students.index');
create 新規作成フォーム表示 〇 
Route::get('/students/create', [StudentController::class, 'create'])->name('students.create');
store 新規保存処理 × 
Route::post('/students', [StudentController::class, 'store'])->name('students.store');
show 詳細表示 〇 
Route::get('/students/{student}', [StudentController::class, 'show'])->name('students.show');
edit 編集フォーム表示 〇 
Route::get('/students/{student}/edit', [StudentController::class, 'edit'])->name('students.edit');
update 更新保存処理 ×
※formに@method('PUT')、@csrfが必要		 
Route::put('/students/{student}', [StudentController::class, 'update'])->name('students.update');
destroy 削除処理 ×
※formに@method('DELETE')、@csrfが必要		 
Route::delete('/students/{student}', [StudentController::class, 'destroy'])->name('students.destroy');

※「resource」を使うとまとめてルーティングできます

Route::resource('students', StudentController::class);

※「except」を使うと特定のルーティングを除外できます

Route::resource('students', StudentController::class)->except('show');
