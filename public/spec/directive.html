概要

ディレクティブとは、PHPの構文を簡潔に書くために使う@から始まる命令文のこと

詳しくはこちらを参照

生PHP

@php

bladeファイルに普通のPHPを書きたいときに使う

@php
    $name = "Taro";
    $list = array(100, 200, 300);
@endphp

分岐・繰り返し

@if

もし～なら

@if (isset($schoolClass))
    <p>変数$schoolClassは存在する</p>
@elseif (empty($student))
    <p>変数$studentは存在しない（または空）</p>
@endif

@if(Route::is('admin.login'))
    <p>管理者ログインのページにこの文言を表示します</p>
@endif

@foreach

配列などから１つずつなくなるまで繰り返す

@foreach ($subjects as $subject)
    <p>{{ $loop->iteration }}．科目名は{{ $subject->name }}です</p>
@endforeach

@forelse

@foreachとほぼ同じ
データが空のときに@emptyが使える

@forelse ($subjects as $subject)
    <p>{{ $loop->iteration }}．科目名は{{ $subject->name }}です</p>
@empty
    <p>まだデータが保存されていません</p>
@endforelse

$loop

繰り返し処理で使えるループ変数
{{ $loop->取り出したい値 }}のように使う

プロパティ 説明
$loop->iteration 1から始まる現在の回数（1, 2, 3...）
$loop->index 0から始まる現在のインデックス（0, 1, 2...）
$loop->first 最初のループのときだけ true になる
$loop->last 最後のループのときだけ true になる

@auth

ログイン済みかどうか

@auth('admin')
    <p>管理者としてログイン中（ログインID: {{ auth('admin')->user()->login_id }}）</p>
@endauth

@guest

@foreachとほぼ同じ
データが空のときに@emptyが使える

@guest('admin')
    <p>管理者ログインをしてください</p>
@endguest

レイアウト

レイアウト側

<!DOCTYPE html>
<html lang="ja">

        <title>@yield('title', 'achieve on step')</title>
    </head>
    <body>
        <header>ヘッダー</header>

        @yield('content')

<html>

@extends('layouts.app')
@section('title', 'マイページ')

@endsection
