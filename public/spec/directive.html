概要

ディレクティブとは、PHPの構文を簡潔に書くために使う@から始まる命令文のこと

詳しくはこちらを参照

{{ }} は自動でエスケープ
{!! !!} は自動でエスケープしない利用者が入力した値にを使ってはいけない
{{-- --}}Bladeのコメントアウト

生PHP

@php

bladeファイルに普通のPHPを書きたいときに使う

@php
    $name = "Taro";
    $list = array(100, 200, 300);
@endphp

ただし、@phpはMVCやパフォーマンスの観点などからコントローラーファイルなどに書くことが推奨されています
例えば、 

@php
    $classes = \App\Models\SchoolClass::query()
        ->with(['teachers' => fn ($q) => $q->orderBy('name')])
        ->withCount('students')
        ->orderBy('name')
        ->get();
@endphp

をコントローラーに書くと、

public function index(): View
{
    $classes = SchoolClass::query()
        ->with(['teachers' => fn ($q) => $q->orderBy('name')])
        ->withCount('students')
        ->orderBy('name')
        ->get();

    return view('admin.classes.index', compact('classes'));
}

または、

public function index(): View
{
    $classes = SchoolClass::query()
        ->with(['teachers' => fn ($q) => $q->orderBy('name')])
        ->withCount('students')
        ->orderBy('name')
        ->get();

    return view('admin.classes.index', [
        'classes' => $classes,
    ]);
}

になります
ビュー側の書き方は内容が同じなら@phpを使った場合もコントローラーを使った場合も変わりません 

@forelse ($classes as $schoolClass)
    <p>{{ $schoolClass->name }}のクラスの人数は{{ $schoolClass->students_count }}人です</p>
    <p>
        担当教師は、
            @forelse ($schoolClass->teachers as $teacher)
                {{ $teacher->name }}先生@if (! $loop->last)、@endif
            @empty
                いません
            @endforelse
        です
    </p>
@empty
    <p>登録されている授業がありません</p>
@endforelse

分岐・繰り返し

@if

もし～なら

@if (isset($schoolClass))
    <p>変数$schoolClassは存在する</p>
@elseif (empty($student))
    <p>変数$studentは存在しない（または空）</p>
@endif

@if(Route::is('admin.login'))
    <p>管理者ログインのページにこの文言を表示します</p>
@endif

@foreach

配列などから１つずつなくなるまで繰り返す

@foreach ($subjects as $subject)
    <p>{{ $loop->iteration }}．科目名は{{ $subject->name }}です</p>
@endforeach

@forelse

@foreachとほぼ同じ
データが空のときに@emptyが使える

@forelse ($subjects as $subject)
    <p>{{ $loop->iteration }}．科目名は{{ $subject->name }}です</p>
@empty
    <p>まだデータが保存されていません</p>
@endforelse

$loop

繰り返し処理で使えるループ変数
{{ $loop->取り出したい値 }}のように使う

プロパティ 説明
$loop->iteration 1から始まる現在の回数（1, 2, 3...）
$loop->index 0から始まる現在のインデックス（0, 1, 2...）
$loop->first 最初のループのときだけ true になる
$loop->last 最後のループのときだけ true になる

@auth

ログインしているとき

@auth('admin')
    <p>管理者としてログイン中（ログインID: {{ auth('admin')->user()->login_id }}）</p>
@endauth

@guest

ログインしていないとき

@guest('admin')
    <p>管理者ログインをしてください</p>
@endguest

@error

エラーがあるとき

@error('login_id')
    <p>{{ $message }}</p>
@enderror

レイアウト

レイアウト側

<!DOCTYPE html>
<html lang="ja">
    <head>
        <title>@yield('title', 'Rollin')</title>
    </head>
    <body>
        <header>ヘッダー</header>

        @yield('content')

        <footer>フッター</footer>
    </body>
</html>

使う側

@extends('layouts.app')
@section('title', 'マイページ')
@section('content')

    <p>ここにページ毎に違うコードを書く</p>

@endsection

@vite

CSSとJSを読み込むタグを出力する
※vite.config.jsのinputにファイル名を書かないと使えません 

@vite(['resources/css/app.css', 'resources/js/app.js'])
// vite.config.js
laravel({
    input: [
        'resources/css/app.css',
        'resources/js/app.js',
    ],
})

@extends

どのレイアウトを使うか

@extends('レイアウト名')
@extends('layouts.app') {{-- layouts/app.blade.phpのレイアウトを使う --}}

@yield、@section

各ファイルごとに違う中身を書くための穴を作る

@yield('content')           {{-- 穴の名前は「content」 --}}
@yield('title', 'Rollin')   {{-- 穴の名前は「title」、子ファイルで使われなかったら「Rollin」が入る --}}
@section('content')
    {{-- 「content」の中身を書く --}}
@endsection

@section('title', 'マイページ')   {{-- 「title」に「マイページ」を入れる --}}

@stack、@push

特定のページだけで使いたい穴を作る

@stack('scripts')    {{-- 子ページで使われなかったら無視される穴 --}}
@push('scripts')
    {{-- 「scripts」の中身を書く --}} 
@endpush

@include

指定したファイルを埋め込む

@include('admin.students.partials.list')
@include('partials.sort-header', ['key' => 'class', 'label' => 'クラス'])
