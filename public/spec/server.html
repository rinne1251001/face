構築方法

PHP設定

サーバーの管理設定＞PHP設定でPHPのバージョンを8.5に変える

データベース作成

サーバーの管理設定＞データベースを開き「データベース作成」をクリック
作成するサーバー：mysql401.phy.lolipop.lan、データベース名にfaceを入力

WinSCPに接続

サーバーの管理設定＞SSH設定を開く
WinSCPの接続項目に、

転送プロトコル SFTP
ポート番号 2222
ホスト名 ssh.lolipop.jp
ユーザー名 書いてあるアカウント
パスワード 書いてあるSSHパスワード

を入力して接続

アップロード方法

軽くするためにLaravelのログを綺麗にする

php artisan optimize:clear
Remove-Item -Path "storage/logs/*.log" -Force
php artisan optimize:clear
Remove-Item -Recurse -Force storage/app/private/faces -ErrorAction SilentlyContinue
php artisan cache:clear file

最初の画面では/home/users/0/アカウント/webにいるので、１つ上に上がって/home/users/0/アカウントのところにfaceフォルダをアップロード
アップロードが終わったらpublicフォルダを全削除
.envの以下の項目を変える（※.envは検索しないと見られない） 

APP_ENV=production
APP_URL=https://（ログインするときに使うドメイン名）
SESSION_SECURE_COOKIE=true
DB_HOST=mysql401.phy.lolipop.lan
DB_DATABASE=データベースのユーザー名-face
DB_USERNAME=データベースのユーザー名
DB_PASSWORD=データベースのパスワード

１つ上に上がって「face」を「rollin」に名前を変える
「web」フォルダに入って「index.php」を作成 

<?php

use Illuminate\Foundation\Application;
use Illuminate\Http\Request;

define('LARAVEL_START', microtime(true));

// Laravel 本体は、公開フォルダ（web）の外の ~/rollin に置く
$base = __DIR__.'/../rollin';

// Determine if the application is in maintenance mode...
if (file_exists($maintenance = $base.'/storage/framework/maintenance.php')) {
    require $maintenance;
}

// Register the Composer autoloader...
require $base.'/vendor/autoload.php';

// Bootstrap Laravel and handle the request...
/** @var Application $app */
$app = require_once $base.'/bootstrap/app.php';

// 公開フォルダは web（このファイルがあるフォルダ）。build/manifest.json などをここから探す
$app->usePublicPath(__DIR__);

$app->handleRequest(Request::capture());

buildフォルダ、modelsフォルダ、imagesフォルダ、.htaccess、robots.txtをpublicフォルダからwebフォルダにコピペ

Tera Termでコマンド

Tera Termの接続項目に↓を入力

ホスト ssh.lolipop.jp
サービス SSH
TCPポート 2222
SSHバージョン SSH2
IPバージョン AUTO

「SHA256」、「このホストをknown hostsリストに追加する」にチェック→続行

ユーザー名 SSHのアカウント名
パスフレーズ SSHのパスワード
認証方式 プレインパスワードを使う

接続したら以下を入力

cd ~/rollin
curl -sS https://getcomposer.org/installer | /usr/local/bin/php8.5
/usr/local/bin/php8.5 artisan migrate --force
/usr/local/bin/php8.5 artisan optimize

/usr/local/bin/php8.5 artisan tinker
App\Models\Admin::create([
    'login_id' => 'admin',
    'password' => bcrypt('12345678'),
]);
exit

エラー確認が終わったら

.envを変更

APP_DEBUG=false
LOG_LEVEL=error

Tera Termでコマンドを打つ

/usr/local/bin/php8.5 artisan config:clear
/usr/local/bin/php8.5 artisan optimize
