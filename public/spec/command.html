サーバー起動

http://127.0.0.1:8000で画面を見る方法

npm run dev　//css適用
php artisan serve　//PHPのサーバー起動

上２つのコマンドを１つのコマンドで打つ

composer run dev

データベース関連

テーブルリセット

php artisan migrate:fresh　//テーブル作り直し
Remove-Item -Recurse -Force storage/app/private/faces　//顔写真削除
php artisan cache:clear　//古い特徴量キャッシュをクリア

テストデータ注入

php artisan migrate:fresh --seed

テーブルリセット＆テストデータ注入

php artisan migrate:fresh --seed

composer関連

①リポジトリクローン時
②ライブラリを追加変更した時
③vendorフォルダを消しちゃったとき 

composer install

.env関連

APP_KEYを変更

APP_KEYとはLaravelの内部でさまざまなデータの暗号化・復号に使われている
使いまわしはセキュリティ的にまずいので変更推奨 

php artisan key:generate

storageフォルダに入れた画像を一般公開

Laravelでアップロードした画像などのファイルを、Webブラウザから一般公開してアクセスできるようにするためのコマンド
公開ディレクトリである public/storage から、実体の保存先である storage/app/public へのシンボリックリンク（ショートカット）を作成することで見れるようになる 

php artisan storage:link

画像を使うときは、

<img src="{{ asset('storage/フォルダ名/ファイル名.jpg') }}">
