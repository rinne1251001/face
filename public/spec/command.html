サーバー起動

http://127.0.0.1:8000で画面を見る方法

npm run dev　//css適用＆カメラも
php artisan serve　//PHPのサーバー起動

上２つのコマンドを１つのコマンドで打つ

composer run dev

データベース関連

テーブルリセット

php artisan migrate:fresh　//テーブル作り直し
php artisan cache:clear file　//古い特徴量キャッシュをクリア
Remove-Item -Recurse -Force storage/app/private/faces -ErrorAction SilentlyContinue　//顔写真削除

テストデータ注入

php artisan db:seed

テーブルリセット＆テストデータ注入

php artisan migrate:fresh --seed

マイグレーションファイルの適用状況確認 データベースに反映されていないマイグレーションが見つかる 

php artisan migrate:status

キャッシュ

各種キャッシュを一括で削除するコマンド
config(設定ファイルのキャッシュ)、route(ルートのキャッシュ)、viewのコンパイル済みファイル、アプリケーションのコンテナ最適化ファイル、イベントとアプリのキャッシュ 

php artisan optimize:clear

composer関連

①リポジトリクローン時
②チームメンバーがライブラリを追加・変更した時
③vendorフォルダを消しちゃったとき 

composer install
npm install

.env関連

APP_KEYを変更

APP_KEYとはLaravelの内部でさまざまなデータの暗号化・復号に使われている
使いまわしはセキュリティ的にまずいので変更推奨 

php artisan key:generate

↓↓ここから先は基本的に１回のみ使用

プロジェクト作成

faceという名前のLaravelプロジェクトを作成

composer create-project laravel/laravel face "13.*" --prefer-dist

Humanをインストール

node_modules/@vladmandicにHuman本体とTensorFlow.jsを入れる

npm install --save-exact @vladmandic/human@3.3.6

public/modelsに学習済みの重み(.bin)とネットワーク構造(.json)を入れる（blazeface、facemesh、faceresのモデル３つ）

New-Item -ItemType Directory -Force public/models/human
Copy-Item node_modules/@vladmandic/human/models/blazeface.*, node_modules/@vladmandic/human/models/facemesh.*, node_modules/@vladmandic/human/models/faceres.* public/models/human/

日本語ファイル追加

追加項目はlang/ja/validation.phpのattributesに書く

composer require laravel-lang/common --dev
php artisan lang:add ja
php artisan lang:update

storageフォルダに入れた画像を一般公開

Laravelでアップロードした画像などのファイルを、Webブラウザから一般公開してアクセスできるようにするためのコマンド
公開ディレクトリである public/storage から、実体の保存先である storage/app/public へのシンボリックリンク（ショートカット）を作成することで見れるようになる 

php artisan storage:link

storage/app/publicに置いた画像を使うときは、

<img src="{{ asset('storage/フォルダ名/ファイル名.jpg') }}">
