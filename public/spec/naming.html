ルーティング

Route::HTTPメソッド('/URL名', [コントローラー名::class, 'メソッド名'])->name('名前付きルート');  // ひとつずつ書く
Route::resource('URL名', コントローラー名::class);  // まとめて書く

// indexのとき、どちらもURLはhttp://127.0.0.1:8000/studentsで、ルート名はstudents.indexになる
Route::get('/students', [StudentController::class, 'index'])->name('students.index');
Route::resource('students', StudentController::class);

Tailwind CSS

基本的な命名規則

「--カテゴリ-変数」
例）--color-bg、--font-sans

使うときは「var(--カテゴリ-変数名)」
例）var(--color-bg)、var(--font-sans)

主なCSSカスタムプロパティ一覧

--color-* 色 color、backgound-color
--spacing-* 長さ・サイズ width、height、margin、padding、gap
--z-* 重なり順 z-index
--font-* フォントファミリー font-family
--text-* 文字サイズ font-size
