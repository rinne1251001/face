基本のcss

cssの優先順位

  1. !important
  2. インラインスタイル
  3. IDセレクタ
  4. クラスセレクタ
  5. 要素名セレクタ

cssが効かない時は↑を確認してください

※要素名セレクタ(divやaなどのタグ)はcssが適用される範囲が広いので、cssファイルに書き込むときは上の方に書いてください

絶対使うcss

div {
    color: black;               \* 文字色 *\
    background-color: white;    \* 背景色 *\
    width: 20px;                \* 横幅 *\
    height: 20px;               \* 縦幅 *\
    padding: 10px;              \* 内側の余白 *\
    margin: 10px;               \* 外側の余白 *\
    border-radius: 10px;        \* 角の丸さ *\
    z-index: 100;               \* 重なり順 *\
    cursor: pointer;            \* カーソルの形 *\
}

色

color: #000000;             /* カラーコードで指定 */
color: black;               /* 色名で指定 */
color: var(--color-font);   /* 変数で指定 */
color: color-mix(in srgb, var(--color-font) 30%, var(--color-bg) 70%); /* 色を混ぜる */

長さ

width: 100px;   /* 画面の1ドット（例は100ドット） */
width: 10em;    /* フォントサイズ（例はフォントサイズの10倍） */
width: 10rem;   /* htmlタグのフォントサイズ（例はフォントサイズ(16px)の10倍） */
width: 100%;    /* 親要素の％（例は親要素いっぱいに広がる） */
width: 100vw;   /* ブラウザの画面の横幅（例は画面いっぱいに広がる） */
height: 100vh;  /* ブラウザの画面の縦幅（例は画面いっぱいに広がる） */

/* calc()は異なる単位を混ぜて計算 */
width: calc(100% - 40px);   /* 100% - 40pxの長さ */

/* clamp()は最小・推奨・最大を指定 */
width: clamp(20px, 10vw, 60px);    /* 基本は10vw、最小幅は20px、最大幅は60px */

flex

要素を柔軟に並べるためのレイアウト機能

display: flex;
gap: 10px;                  /* 隙間の大きさ */
justify-content: center;    /* 横方向に中央揃え */
align-items: center;        /* 縦方向に中央揃え */

justify-contentの値

grid

要素を縦横の２次元に配置するためのレイアウト機能

display: grid;
gap: 10px;                /* 隙間の大きさ */
justify-content: center;  /* グリッド全体のトラックを横方向に中央 */
justify-items: center;    /* 個々のアイテムを横方向に中央 */
align-content: center;    /*グリッド全体のトラックを縦方向に中央  */
align-items: center;      /* 個々のアイテムを縦方向に中央 */

place-content: center;    /* グリッド全体のトラックを縦横に中央 */
place-items: center;    /* 個々のアイテムを縦横に中央 */

grid-template-columnsやgrid-columnを使うと好きな場所に配置できます

Googleフォントアイコン

使い方

①Googleフォントアイコンのページから使いたい記号を探す
②<head>タグの中にコピーしたリンクを貼る 

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200&icon_names=search" />

③使いたい場所にコピーしたInserting the iconを貼り付け

<span class="material-symbols-outlined">search</span>

④Googleフォントアイコン全体に適用したいcssはmaterial-symbols-outlinedクラスのcssに書いてください

.material-symbols-outlined {
    /* アイコンの大きさ */
    font-size: 3em;
    /* アイコンの色 */
    color: green;
}

複数の場合

複数のアイコンを使いたい時はリンクの最後にアルファベット順＆カンマ区切りでアイコンの名前を書いていってください

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,400,0,0&icon_names=home,search,setting" />

メディアクエリ（レスポンシブル対応）

@media

スマホやパソコンなど画面幅ごとに違うcssにしたい時に使います
王道の数値は640px、768px、1024px、1280pxです
実例はハンバーガーメニューの「ヘッダーのレスポンシブル」を参照 

/* @mediaの外は共通設定 */
.sp {
    width: 20px;
    height: 20px;
    background-color: yellow;
}
.pc {
    width: 60px;
    height: 30px;
    background-color: pink;
}

/* 768px未満のとき */
@media (width < 768px) {
    /* パソコン用は非表示にする */
    .pc {
        display: none;
    }
}

/* 768px以上のとき */
@media (min-width: 768px) {
    /* スマホ用は非表示にする */
    .sp {
        display: none;
    }
}

storage/app/privateフォルダの写真

指定した１枚の写真を表示する

@php
    // storage/app/private を指すディスク
    $disk = \Illuminate\Support\Facades\Storage::disk('local');

    // 顔写真の名前を指定（例：488054e6-999f-455a-acd7-95380db3e5d4.jpg）
    $uuid = '488054e6-999f-455a-acd7-95380db3e5d4';
    $path = collect($disk->allFiles('faces'))->first(fn ($p) => str_contains($p, $uuid));

    // 画像の中身を base64 にして、HTML の中に直接埋め込む
    $src = $path ? 'data:image/jpeg;base64,' . base64_encode($disk->get($path)) : null;
@endphp

@if ($src)
    <img src="{{ $src }}">
@else
    <p>画像が見つかりません。

@endif

storage/app/private/facesフォルダの写真を５枚表示する

@php
    $disk = \Illuminate\Support\Facades\Storage::disk('local');
    $files = collect($disk->allFiles('faces'))->take(5);
@endphp

@foreach ($files as $file)
    <img src="data:image/jpeg;base64,{{ base64_encode($disk->get($file)) }}">
@endforeach

カレンダー

全体用カレンダー

データベースに登録されている全ての教科を表示したカレンダー

<!DOCTYPE html>
<html lang="ja">

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>カレンダーテスト</title>
    @vite(['resources/css/test.css', 'resources/js/app.js'])
    <style>
        .calendar {
            display: inline-grid;
            grid-template-columns: auto repeat(5, 1fr);
            border-top: 1px solid var(--color-font);
            border-left: 1px solid var(--color-font);
        }

        .calendar thead,
        .calendar tbody,
        .calendar tr {
            display: contents;
        }

        .calendar th,
        .calendar td {
            padding: 10px;
            border-right: 1px solid var(--color-font);
            border-bottom: 1px solid var(--color-font);
            text-align: center;
        }

        .calendar th {
            color: var(--color-bg);
            background-color: var(--color-accent);
        }

        .calendar th:first-child {
            width: 3em;
        }
    </style>
</head>

<body>

    @php
        // 全科目を取得（同じ枠に複数ある場合の並び順を固定）
        $subjects = \App\Models\Subject::orderBy('period_start')
            ->orderBy('name')
            ->get();

        // 月〜金だけ取り出す（[1 => '月', … 5 => '金']）
        $days = array_slice(\App\Models\Subject::DAYS, 0, 5, true);

        // $grid[時限][曜日] = その枠の授業
        $grid = [];
        foreach ($subjects as $subject) {
            foreach (range($subject->period_start, $subject->period_end) as $period) {
                $grid[$period][$subject->day_of_week][] = $subject;
            }
        }

        // 表示する行数（全科目の最後の時限まで）
        $maxPeriod = $subjects->max('period_end') ?? 1;
    @endphp

    <table class="calendar">
        <thead>
            <tr>
                <th></th>
                @foreach ($days as $label)
                    <th>{{ $label }}</th>
                @endforeach
            </tr>
        </thead>
        <tbody>
            @for ($period = 1; $period <= $maxPeriod; $period++)
                <tr>
                    <th>{{ $period }}限</th>
                    @foreach ($days as $day => $label)
                        <td>
                            @foreach ($grid[$period][$day] ?? [] as $subject)
                                <div>{{ $subject->name }}</div>
                            @endforeach
                        </td>
                    @endforeach
                </tr>
            @endfor
        </tbody>
    </table>

</body>

</html>
