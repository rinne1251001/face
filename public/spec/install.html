git

インストールしたらVS Codeのターミナルに、

git config --global user.name "あなたのGitHubのユーザー名"
git config --global user.email "あなたのメールアドレス"

php8.5

①PHPダウンロードページの「VS17 x64 Thread Safe」の「Zip」をクリックしてインストール→展開
②C:\xamppにあるphpフォルダを「php_old」にリネーム
③①をC:\xamppに移動して名前を「php」にする
④③にある「php.ini-development」をコピペして「php.ini」にリネーム＆↓のコメントアウトを外す 

extension_dir = "C:\xampp\php\ext"
extension=curl
extension=fileinfo
extension=gd
extension=intl
extension=mbstring
extension=openssl
extension=pdo_mysql
extension=pdo_sqlite
extension=zip

余裕があれば以下も↓

date.timezone = Asia/Tokyo    ; PHPの日付の基準を日本時間に
upload_max_filesize = 20M   ; 1回あたりにアップロードできるファイルの最大サイズを20M
post_max_size = 25M ; POSTリクエスト全体の最大サイズを25メガバイト ※upload_max_filesizeより大きい値にすること
memory_limit = 256M ; 1つのスクリプトが使用できる最大メモリ量を256M
opcache.revalidate_freq=0   ; ファイルの変更がすぐ反映
opcache.memory_consumption=256  ; OPcacheに割り当てるメモリのサイズを本番環境向に
opcache.interned_strings_buffer=16  ; 文字列キャッシュ用に割り当てるメモリのサイズ
opcache.max_accelerated_files=20000 ; キャッシュできるスクリプトファイルの最大数を大規模フレームワーク向けに

本番環境向け↓
※開発環境では設定しない

opcache.validate_timestamps=0   ; ファイルのタイムスタンプを再検証しない
display_errors = Off    ; 画面上に直接エラー内容を出力・表示しない
display_startup_errors = Off    ; PHPの起動シーケンスで発生したエラーを画面に表示しない
error_reporting = E_ALL & ~E_DEPRECATED ; 非推奨の古い書き方以外のすべてのエラーを出力
zend.assertions = -1    ; assert()関数の実行を無効し実行速度を上げる
zend.exception_ignore_args = On ; 例外が発生してもトレース情報に引数の値を含めない
zend.exception_string_param_max_len = 0 ; 例外メッセージに含める文字列パラメータの最大長を0に
mysqlnd.collect_memory_statistics = Off ; MySQLのネイティブドライバのメモリ使用統計の収集をオフ
expose_php = Off    ; HTTPレスポンスヘッダーのPHPのバージョン情報を隠蔽

composer

①composerダウンロードページの「Composer-Setup.exe」をクリックしてインストール
②インストーラーの選択は「Recommend」→あとは☑を入れない

Node.js

①Node.jsダウンロードページの「Windows Installer (.msi)」をクリックしてインストール→展開
②「環境設定を編集」→新規で、変数名PATH、変数値C:\Program Files\nodejs\に設定
③ターミナル(管理者)で以下のコードを打つ 
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

リポジトリコピー後にする作業

VS Codeターミナルで、

composer install
npm install
