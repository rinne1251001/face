git

インストールしたらVS Codeのターミナルに、

git config --global user.name "あなたのGitHubのユーザー名"
git config --global user.email "あなたのメールアドレス"

php8.5

①PHPダウンロードページの「VS17 x64 Thread Safe」の「Zip」をクリックしてインストール→展開
②C:\xamppにあるphpフォルダを「php_old」にリネーム
③①をC:\xamppに移動して名前を「php」にする
④③にある「php.ini-development」をコピペして「php.ini」にリネーム＆↓のコメントアウトを外す 

extension_dir = "C:\xampp\php\ext"
extension=fileinfo
extension=zip
extension=openssl
extension=pdo_mysql
extension=mbstring
extension=curl

composer

①composerダウンロードページの「Composer-Setup.exe」をクリックしてインストール
②インストーラーの選択は「Recommend」→あとは☑を入れない

Node.js

①Node.jsダウンロードページの「Windows Installer (.msi)」をクリックしてインストール→展開
②「環境設定を編集」→新規で、変数名PATH、変数値C:\Program Files\node.js\に設定
③ターミナル(管理者)で以下のコードを打つ 
Ser-ExecutionPolicy RemotoSigned -Scope CurrentUser

リポジトリコピー後にする作業

VS Codeターミナルで、

composer install
npm install
